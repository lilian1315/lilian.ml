My projects

create-element

Originally, I wanted a simple way to create HTML elements in JavaScript, but I never found a solution I liked. My constraints: a type-safe API that's easy to update. Then I wanted to see if it was possible to support signal libraries such as Preact Signals or Alien Signals. I ended up implementing JSX support and found myself with a micro UI framework!

faisceau

An interface for Alien Signals inspired by Preact Signals with utility functions tailored to my needs. Building this library helped me better understand how Alien Signals works under the hood, in particular the "double-linked-list" concept. It's one of the signal libraries supported by create-element.

faisceau ui

A UI library based on Zag with a base style inspired by Shadcn and following the principle of progressive enhancement. A chance to try out both previous libraries, and my attempt at building the best multi-select for vanilla JavaScript.
